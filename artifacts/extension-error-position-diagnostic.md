# Extension DEV 错误答案的图位置（事后描述）

仅 d9–12，共 512 道同一 DEV。j 是答案节点相对起点的图距离，不是模型内部实际计算步数。每行观察值与基线都只使用该行实际答错的同一批题；基线为逐题七个错误备选节点的均匀分布。不同模型/出口的错误题集不同，不把残差差异解释成配对效果。

- Extension 的主要错误表现是答案节点偏早：T8 错误中 87.4% 早于目标，同题选项基线为 45.9%；四个 hop 分别为 93.6%、86.8%、82.0%、89.4%，均高于各自基线。其 T4/T6/T8 汇总众数分别为 j=6/7/7，而 T16 为 j=1，没有看到“增加出口循环就主要错到目标之后”的统一模式。
- 确有落在短距离范围的输出集中，但不能简单称作返回已训练 hop：Extension/T8 有 78.0% 错误落在位置 1–8，基线 35.6%；限制到实际训练过的 {1,2,3,4,6,8}，则为 43.5% 对 26.1%。众数 j=7 并非训练过的 query 长度。T16 在 d10/d11/d12 上的 j=1 错误数为 39/22/31，同题条件期望仅 6.3/5.3/5.4。
- 初始模型与 Control 的汇总也多偏早，但有明显 hop 差异，不能用一个 pooled 数字概括：Control/T8 的 d9 错误有 96.1% 晚于目标（基线 63.4%），d11/d12 错误却分别有 82.0%/91.7% 早于目标（基线 44.5%/50.8%）。这些都是各自实际错误子集内的描述，不是跨模型配对效果，也不证明内部算法、训练因果或应改选出口。
