# Ouro 深度扩展：实际递推与稳定性边界

2026-09-13。本笔记是对已导入实现的静态数学审计，不是新实验结果，也不修改 V4。它解释哪些稳定性目标可能有用、哪些会与保留题目信息矛盾。

## 当前程序实际计算什么

`ouro_depth/model.py:140` 只在开始用冻结 embedding 形成整个提示的状态 H0。此后每轮都执行同一组 decoder layers，再执行共享 RMS norm。固定的 attention mask M 和 RoPE P 在所有轮共用；`past_key_value=None`、`use_cache=False`。供应方 attention 中的 `current_ut` 仅在有 KV cache 时参与缓存层编号，没有在本次无缓存前向中变成循环位置 embedding。原始供应方前向同样在循环外设置输入 embedding，然后反复更新状态。因此当前确实是在扩展一个共享的递推，并非索引到新的一组层参数：

\[
H_0=E(x),\quad H_{r+1}=F_\theta(H_r;M,P),\quad z_r=W H_r^{\mathrm{answer}}.
\]

E 和 W 冻结；theta 包含共享 decoder 与每轮 RMS norm。原始 token embedding 不在每轮重新注入。这里的 H 包括整段提示，不能把它等同为一个显式图节点或一条已验证的推理步骤。

## 更深的梯度路径不自动等于更好的算法

令 J_r 为 F 对 H_r 的 Jacobian，g_r 为损失对 H_r 的梯度。完整反向传播遵循

\[
g_r=J_r^\top g_{r+1},\qquad
\nabla_\theta L_R=\sum_{r=0}^{R-1}(\partial_\theta F_\theta(H_r))^\top g_{r+1}.
\]

即使每轮 RMS norm 控制了状态尺度，也没有因此证明 Jacobian 的连乘稳定、方向与任务目标一致或信息得到保留。V4 观察到的裁剪前梯度尖峰与这一风险相容，但不是它的因果证明：两臂的参数轨迹已经不同，任务混合与学习率也影响优化。

单个终点 CE 只约束该终点的答案分布。T4 学会 d8，并不推出 T8/T16 仍答对；同样，T8 恢复训练题也不推出 T16 能解决未训练长度。多出口监督为选定的浅、深输出提供额外约束，但仍不证明所有后续轮或未见长度有效。新 tiny CPU 验证只证明这种分支梯度能正确实现，并且辅助 T4 不需要额外再展开四轮；它不是有效性证据。

## 不应无条件追求整段状态的全局收缩

固定参数 theta，考虑两个不同题目 x、x'，具有相同长度、mask、positions 和答案读取位置。当前递推的题目内容只在各自 H0 中。假设同一个 F 在包含这两条轨迹的区域内满足统一的两点收缩条件，常数 q<1；取整个状态的欧氏范数，则

\[
\|H_R(x)-H_R(x')\|\le q^R\|E(x)-E(x')\|.
\]

相应 readout 的 logit 差也会随之趋近零。因此，如果两题要求不同答案且都要保有固定的正分类 margin，随着 R 无限增大，这与上述全局收缩假设不相容。这是一个有条件的理论警告，不是声称实际 Ouro 已满足该假设。仅在有限深度范围内收缩也不必然有害；趋向同一极限但 margin 衰减的不同 argmax，在数学上仍可能短期甚至渐近存在，只是没有稳健的正 margin 保证。

更具体地，若两题的正确答案分别为 a、b，且均保持相对于另一个答案至少 gamma>0 的 logit margin，则答案位置状态 h 必须满足 `(w_a-w_b)·(h_R(x)-h_R(x')) >= 2 gamma`。其绝对值却至多为 `||w_a-w_b|| q^R ||H0(x)-H0(x')||`，随 R 趋零。矛盾依赖固定正 margin 和无限深度；它没有给出当前模型在 T8 或 T16 出错的阈值。

更合理的稳定性目标可以是不同题目落入不同的局部吸引域，或在每轮显式保留/重新注入题目条件，使递推成为 F(H,x)。在后一种结构中，对 H 的条件收缩可以容许随 x 改变的稳定解。二者都只是机制方向，不能由当前 logits 或梯度范数直接判定已有吸引域，也不自动保证推理收益。不能用“让状态完全不变”替代困难题上额外循环带来的实际改进。

## 当前证据如何使用

V4 的固定4组在 DEV400/800 对所有题给出同一答案，证明的是输出退化；隐藏状态是否也相同、图结构信息是否消失，没有被测量。旧 V3 更多循环下的错误选项若偏向目标之后，也必须相对于每题实际可用的错误选项做校正，且最多支持输出层面的方向偏好，不能证明内部按图一步步前进。相关离线诊断使用保存的预测，不新增评分，不用于挑选本轮终点。

当前 V4 继续运行至原定固定预算。任何初始化迁移、课程或多出口保持机制都需要另行固定实验与强多出口对照，并在新的独立确认集上检验真正的难题收益。
