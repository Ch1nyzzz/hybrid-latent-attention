# v3：任务难度与训练循环深度的配对实验

状态：已采用，协议在任何 v3 训练或模型评分之前定稿。实现与数据准备正在进行；本文件本身不表示训练已启动。用户已授权自主设计数据和实验并使用可用GPU，无需新增审批。

## 1. 采用依据与证据边界

v2 两组均按原定2B计算代理预算完成。循环课程组在已见 d6/8 开发题上由T4的88.67%升至T8的92.58%，但低于固定4循环训练在T4的96.88%。原 v2 sealed 确认的开发门槛不满足，因此保持其 IID/OOD 未评分。

随后按预先写好的 EXTRAPOLATION_PROBE.md，对最终模型和共同初始化评估512个新9–12跳开发实例。固定4循环训练模型在T4/6/8/12/16上的准确率为15.63/53.32/29.49/11.91/9.96%；当前循环课程组为16.60/13.67/13.28/12.50/9.57%。固定组T4→T8增益13.87pp，140错→对、69对→错；对两个模型筛选比较做Bonferroni校正后的保守近似95%区间为[5.03,22.37]pp。两个模型已学会训练过的难题，且d1T4均保持100%。这些结果满足此前候选协议的采用条件。

这支持检验训练时的难度与深度配对是否影响泛化；它不证明 v3 会有效，也不能把 v2 开发外推结果当作 v3 独立确认。T6的开发峰值没有替代本轮预先选定的T8终点。固定4循环模型的额外循环收益也不能归功于深循环训练。

假设：v2独立采样任务和出口深度的正确答案CE，容易同时奖励短出口答对与长出口保持。让较难任务配较多循环，可能改善额外循环处理未训练题目长度的能力。该假设不要求内部一轮走一条边，也不以隐藏状态收敛或梯度冲突为已证事实。

## 2. 三臂与共同设置

所有臂从同一个最终500M one-hop checkpoint-416 初始化，重置 Adam；不从挑选的 v2 中途点继续。每臂名义预算均为 **2B** `padded_tokens × 24 × 4 × T`，这是训练开销代理，不是实测 FLOPs。离散 batch 造成的终点误差、有效 token 数和实际总开销必须报告。

| 臂 | 每个同质难度 batch 的 T |
|---|---|
| conditional | d1/2→T4，d3/4→T6，d6/8→T8 |
| independent | 在同阶段内随机置换 conditional 的整条 T 序列，破坏难度与 T 的配对 |
| fixed4 | 所有难度均为 T4；同 2B 开销，作为实用基线 |

三个臂都用同质 difficulty 的 optimizer batch：每次更新的 16 个例子具有同一 d，microbatch=8。不能拿 v2 的混合难度 batch 训练结果充当这里的 fixed4 控制。原始模型固定为ByteDance/Ouro-1.4B revision574fa66cb8bf5abdc979642d01cf2b79b16bfab1；共同初始化在reds-lab的`/data/erv1n/ouro-depth-20260913/diagnostics/diagnostic-onehop-s20260913/checkpoint-416`。训练seed20260914。模型结构、可训练参数、单出口答案CE和数据格式沿用v2；AdamW(.9,.95)、LR1e-5、weight decay.01、clip1、FP32参数/Adam及BF16前向；完整 BPTT 与 checkpointing，不添加浅层错误标签、梯度截断、单调性奖励或新 halting 机制。

| 预算阶段 | q(d1,d2,d3,d4,d6,d8) | conditional / independent 的 T4,T6,T8 目标边缘分布 |
|---|---|---|
| 0–15% | .20,.60,.20,0,0,0 | .80,.20,0 |
| 15–40% | .10,.20,.30,.40,0,0 | .30,.70,0 |
| 40–70% | .10,.10,.10,.25,.45,0 | .20,.35,.45 |
| 70–100% | .10,.05,.05,.15,.30,.35 | .15,.20,.65 |

## 3. 配对控制与可恢复执行

采用预生成清单方案，而非只匹配期望边缘分布。按表中 q 生成每阶段的共同 batch 清单及例子 ID，记录 conditional 的 T=f(d)，再用独立 RNG 在阶段内置换 T 给 independent。每阶段的实际 T 次数、样本顺序、更新数因此完全相同；随机置换并不保证有限样本的 d–T 列联表恰好独立，必须报告实际列联表，不能按结果重新抽置换。

所有训练 batch 固定为同一 padding width L；L 在启动前从训练数据及 tokenizer 确定，保证无截断。这样 conditional 与 independent 的每阶段总开销代理精确一致，长度与 T 的相关性也不会改变总开销。以 conditional 清单累计开销达到预定阶段界限（累计 0.3/0.8/1.4/2.0B）确定共同阶段终点；independent 按同一清单边界推进，不能各自按实时开销重新切阶段。最后一次更新的预算超额有界并公开。

两匹配臂在相同更新位置使用相同 LR：阶段内以 `阶段起点实际开销 + 已完成更新数 / 阶段更新数 × 阶段实际总开销` 作为共同调度进度，保持 5% warmup 与 cosine。否则置换 T 会连带改变同一个例子的 LR。fixed4 使用相同开销进度曲线、阶段任务分布和固定 L，运行到同样的阶段预算（最多一更新的取整差）；每阶段先用同一批次流的共同前缀，再继续该流取得额外更新。它在同预算下会看到更多例子；这是固定开销基线的属性，不能声称它与另外两臂曝光相同。

预先固定并分别保存任务类别 RNG、每个 d 的无放回 pool/shuffle RNG、T 置换 RNG 和模型 RNG。阶段清单及每臂游标随 checkpoint 保存，resume 不重抽清单；任务选择和 T 都不依赖答案、模型正确率或开发集表现。启动前需验证一次实际trainer的中断续训等价，以及清单的样本、T 计数和开销匹配。固定 padding 的额外成本和保存清单的工程量有限，值得用于隔离本实验的核心变量。

## 4. 数据、冻结终点与防止伪收益

沿用 25 节点、随机双字母标签、原始无缩进边列表和 A–H 选择格式。数据位置`data/v3-pointer`，seed17601。新训练集24,000（d1/2/3/4/6/8各4,000）；图身份排除所有先前实验，答案不参与采样。新DEV共1,280条，上述六种已见难度及9/10/11/12各128条；另生成从未用于设计选择的sealed test共5,120条：已见 d1/2/3/4/6/8 每跳 512 条，以及**主要长度泛化集 d9/10/11/12 每跳 512 条**，每跳答案均衡。原 v2 sealed 和此次用于采用决策的新增 DEV 始终保留原身份，不能改名为 v3 主终点。

只比较预定最终预算 checkpoint。主指标是新 sealed d9–12 汇总的全词表正确率，T4→T8 配对；选择内正确率及每跳结果为次要指标。报告 wrong→right、right→wrong、保守配对置信区间及 exact McNemar。要支持难度与循环配对改善推理的完整结论，须同时满足：

- conditional T8 胜过自身 T4、fixed4 臂的 T4、independent 臂的 T8，三项预定配对增益的 95% 下置信界都大于 0；第三项才隔离“难度与 T 配对”的贡献。
- conditional 的 d1 T4 相对初始化须保持在 2 个百分点以内。另完整报告已见 d6/8 与新 d9–12 的 T4 相对 independent、fixed4 和初始化的差值及区间。硬题浅层下降超过 2pp 时，不能声称整体能力保持或无代价改进；但若 T8 的绝对准确率仍超过以上两个训练控制，则可以报告存在浅层代价的深层收益。这里的 2pp 是点估计护栏，不是统计非劣效性证明。

若 T8−T4 变大只因为 T4 下降，且 T8 没有胜过训练控制组，应报告深度专门化或退化，不能归因于额外的绝对能力提升。若 T8 胜过控制组而硬题 T4 有下降，须同时报告深层收益和浅层代价；本阶段用户目标并不要求所有难题在浅层也保持最优。简单题保持护栏仍为必需。T6/T12/T16、原 v2 OOD 和中途 DEV 曲线均不能补救失败的主终点。

本实验检验的是**未见题目长度的泛化**：T8 本身在训练中出现过，不能声称未见循环深度外推。未来确认工具必须显式新增 v3 的 d9–12 主分组，不能沿用现有比较器的 `hard=d6/8` 决策。一次 seed 是探索性证据；算术迁移、普遍 LLM 推理和自适应计算均留待独立实验。


## 5. 执行、审查和候选冻结

纯计划逻辑位于v3_plan.py，独立训练入口为train_v3.py，复用已验证的Ouro模型与评估函数。启动前导出共同plan.json，在三臂运行目录中绑定同一计划，验证固定padding无截断、配对两臂样本/更新数/T次数/阶段总compute/LR完全一致。训练保存计划、游标、模型、Adam与全部RNG；恢复不能重抽任务或深度计划。

实现批次风险为中等：风险集中于计划语义、计算量匹配和断点恢复。最小验证是计划计数/阶段/LR不变量，以及pinned CPU tiny模型的一次中断恢复等价；根代理作一次聚焦审查。已验证且未改动的模型前向/梯度全套不重复运行。新数据全量独立语义验证，并在传输后进行一次完整性检查。计划身份摘要用于确定性和恢复绑定，不对普通源码反复做哈希。

每200更新及最终评估全1,280条DEV，深度4/6/8；每400更新及最终保存检查点。完整计划规定停止位置；max3000更新仅作工程上限，到上限但计划未完成不能算完成。固定4基线允许在两张卡之一空闲后顺序启动。仅使用已分配的reds-lab GPU4/5，启动前确认内存和compute occupants均无其他任务；记录真实PID、GPU UUID、命令和源代码快照。

只按最终固定预算选检查点。最终DEV的conditional T8相对自身T4、independent T8及fixed4 T4的三项点增益均为正且d1护栏通过时，冻结三臂最终候选并一次性评估新sealed test，包含共同初始化。DEV上的区间用于描述；确认判断以新test的预定主组d9–12为准。若开发门槛失败，则保留test并报告失败。不要按中途峰值或最佳循环数替换主比较。

新test报告conditional T8相对fixed4 T8的同深度比较。如果它不胜过固定训练模型的相同推理深度，不能声称这套训练优于固定4训练后再增加推理循环；即使conditional超过independent，也只说明难度配对优于相同边缘分布的独立采样。完整报告所有条件和浅层代价，不把某一项通过等同于所有目标达到。
