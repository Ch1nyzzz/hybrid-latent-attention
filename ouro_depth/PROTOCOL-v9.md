# V9：学会何时停——冻结循环体上的停止门（监督 vs GRPO）

状态：2026-09-13 起草；在 V6 最终检查点上的正式运行前冻结。工程试跑（`diagnostics/v9-smoke/`，中途检查点、小样本）不计入结论。

## 1. 问题

V6 表明逐轮监督能让循环块每轮精确走一跳并外推到 3–4 倍深度，但不带保持目标的模型在 T≠d 时全错，带保持目标的模型走得不够远。研究目标的最终形态需要模型**自己决定停在哪一轮**。本实验把停止建模为循环体之外的一个门，循环体冻结：一次前向到 T_max=16 得到每个出口的答案位置状态与答案，因此停止问题是对出口的**上下文赌博机**（确定性环境、奖励可精确枚举）。

用户提议的 GRPO（同一题采样不同停止深度、按结果强化）在此可精确实现；因为奖励可枚举，同时给出监督版（目标 = 答对的出口集合上的均匀分布）作为上界对照。GRPO 的价值在于它不需要枚举奖励，可迁移到答案需要 rollout 的任务。

## 2. 设置

- 循环体：V6 最终检查点（1448 步）的 `step_nohold`（只走）与 `step`（走 + 保持），冻结。
- 门：`LayerNorm(无仿射) → Linear(H→1) → sigmoid` 给出每轮停止概率 g_r，停止分布 p(r) = g_r ∏_{j<r}(1−g_j)，第 16 轮强制停止；零权重初始化、偏置 logit(1/15) 使初始分布分散。
- 训练数据：V6 训练集的 4,096 题（d≤8）；一次抽取缓存 [N,16,H] 状态与 [N,16] 正确性。
- 监督：−Σ_r target_r·log p(r)，target 在答对的出口上均匀。
- GRPO：每题采样 G=8 个停止深度，奖励 r = 1[答对]·(1 − λ·t/16)，λ=0.1（只在答对的出口间偏向更早；答错一律 0，避免在探索前塌缩到第 1 轮——工程试跑中减法惩罚会导致这一塌缩），组内标准化优势，PPO 比率裁剪 0.2，熵奖励 0.01，Adam 1e−3，1,500 步。
- 评估：DEV（d1–12 各 128）与 33 节点探针（d13–16）；指标为“门选出口（argmax）处答案的正确率”、平均选中出口对 d 的曲线、`exit==d` 比例；对照为“最佳单一固定出口”和“任一出口答对”的 oracle。

## 3. 预先固定的判断（主组未见 d9–12，n=512）

1. 门选出口正确率 ≥ 80%（step_nohold 体上 oracle 接近 100%，因此这是对门本身的要求）。
2. 门选出口正确率显著高于最佳单一固定出口（配对 McNemar p<.05）。
3. 探针 d13–16 上门选出口正确率 ≥ 60%（停止规则对未见深度外推）。
4. GRPO 与监督版的差距 ≤ 5pp（否则报告为“可枚举奖励下 RL 的样本效率损失”）。

通过判断 1–3 即为研究目标的自适应计算形态在本任务上的首次实现；不通过则报告“状态中不含可读的‘已完成’信息”并转向让循环体在训练中表达完成信号（step 臂或显式完成 token）。

## 4. 边界

- 门只看答案位置的状态；不改循环体。若 step_nohold 的状态不携带“剩余步数”，门只能靠状态的表面统计（例如落点处节点的“是不是目标”无法从状态直接得到），失败是有信息量的结果。
- GRPO 在此是带组基线的 REINFORCE；不声称验证了完整的 GRPO 训练动力学。
- 单 seed；训练集与 V6 相同，不开封 test。
