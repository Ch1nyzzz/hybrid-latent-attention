# V8：逐轮“中间值”监督——V6 机制在算术链上的复现

状态：2026-09-13 起草，任何 V8 模型评分前冻结。目的：检验 V6 发现的“每轮一个可监督步”是否与图结构无关，并给出数学任务的最小版本。

## 1. 任务（arith_value）

模 7 的仿射运算链：`a = 4`，`b = (3 * a + 5) mod 7`，……共 25 条方程（33 条用于探针），打乱顺序；问某个变量的值，答案是 `Answer:` 后紧跟的一位数字（Ouro 分词器中 0–6 各为单 token；多位数会被拆成单个数字，因此模数取 7）。难度 d = 从基值到查询变量的运算步数。每行的 `metadata.path` 是从基值起每一步的值，因此第 r 轮出口可以监督“做完 min(r, d) 步后的值”。随机猜对概率 1/7。

数据 `data/v8-arith`（`prepare_v8_data.py`，seed 20260921）：训练 d∈{1,2,3,4,6,8} 各 4,000；DEV d1–12 各 128；密封 test d1–12 各 512；探针 33 条方程、d13–16 各 64。每行独立求解验证。

## 2. 设置与臂

与 V6 完全相同的计划、课程、优化器与四臂（`v6_plan.py`、`train_v6.py` 已支持 `arith_value` 族）：

| 臂 | 监督 |
|---|---|
| step | 出口 r=1…T，目标 = 做 min(r, d) 步后的值 |
| step_nohold | 出口 r=1…d，目标 = 做 r 步后的值 |
| terminal | 仅出口 T，目标 = 最终值 |
| fixed8 | T 恒 8，仅出口 8 |

原始 Ouro-1.4B 初始化，1,448 更新，四阶段难度课程，T = d + U{0..4}，完整 BPTT，峰值 LR 1e-5。评估出口 T=1…16（探针到 24）。`landed_hop` 在本族定义为：预测值等于路径上某一步的值时，取离“期望步 min(T, d)”最近的那一步；值在模 7 下会重复，因此它只是辅助诊断。

## 3. 预先固定的判断（主组未见 d9–12，n=512；主终点 1,448）

与 V6 相同（`compare_v6_predictions.py`）：判断 4（一步一轮外推：d9–12 各自在 T=d 出口 ≥ 50%）是本实验的核心；判断 1–3 与 5–6 决定 step 臂能否同时保持。额外记录 step_nohold 的 T=d 对角线：若与 V6 一样在未见步数上高正确率，则“每轮一个可监督步 → 深度外推”这一机制与任务无关。

## 4. 边界

- 模 7 使随机基线为 14.3%，且值会周期性重复，评估用的是全词表 argmax 与目标 token 的精确匹配，不受此影响；`landed_hop` 受此影响，仅作参考。
- 这是数学的最小形式（单步算子、单 token 值）。真实题目还需要把解题过程规范成等粒度的原子步并处理多 token 中间值，这属于后续工作。
- 停止规则同 V6：非有限/OOM 停止；门槛失败不调参；密封 test 只在通过后一次性评分。
