# v3 候选：任务难度与循环深度的配对是否有帮助？

**状态：CANDIDATE，尚未选为下一轮实验。** 本文件只提出一个三臂实验；不改变正在运行的 v2、其确认标准或 sealed 数据用途。v2 的两个完整 2B 终点和新增 9–12 跳 DEV 结果目前尚未齐备，不能据中途曲线决定启动。

## 1. 假设与采用条件

v2 对同一正确答案在不同 T 上施加 endpoint CE。当任务已能在 T4 完成时，这个目标鼓励各出口都答对，并不要求 T8 胜过 T4；但它也不必然压制深层计算。尚无梯度测量证明存在梯度冲突。候选 v3 只检验：**在任务、深度边缘分布和训练开销相同的情况下，让较难题配较大 T，能否改善未训练过的题目长度上的额外循环收益？** 不假设一轮等于一步指针移动。

采用前先完成原 v2 的最终开发比较；仅在原协议规定的开发证据成立时执行其 sealed 确认，否则保留 sealed 集。随后只用两组最终 2B checkpoint 评估新增 9–12 跳 DEV。T4/T6/T8/T12/T16 全部报告；不挑中间 checkpoint，不以最佳 T 代替 T8。以下为候选采用门槛，须在读取该 DEV 结果前确认；若结果已经读过，则这些门槛只能算事后设计依据：

1. v2 至少一组最终模型在已训练 d6/8 上的 T4 或 T8 准确率达到 80%，且两组 d1 的 T4 保持在共同初始化的 2 个百分点以内。先确认基本学习和浅层保持能力。
2. v2 的“已见难题 T4 已足够”（例如 d6/8 T4 ≥90%）或“课程组未取得原协议要求的 T8 增益”，确实留下新的设计问题。若 v2 已成功，优先完成其确认和复现；本候选不是替代成功标准。
3. 新增 9–12 跳 DEV 存在 T4 的余地（至少一组 T4 <90%），并且**同一组**最终模型的预定 T4→T8 配对增益至少 +5 个百分点、下置信界大于 0。两组都检查时，对这两个筛选比较做 Bonferroni 校正。该结果只是采用新假设的开发证据，不能充当 v3 的确认结果。

若只有 T12/T16 有信号，不能据此采用本文件的 T4/6/8 映射；若各 T 都接近随机、已见难题尚未学会、简单题明显退化，或 T4 在新增 DEV 也已接近满分，则暂不采用。**“v2 没有深度收益”本身不构成 v3 会有效的证据。** 尤其，早期课程组已训练 d1–4 却未泛化到 d6，不能把重复短题训练宣称为解决办法。

## 2. 三臂与共同设置

所有臂从同一个最终计划 500M 的 one-hop checkpoint 初始化，重置 Adam；不从挑选的 v2 中途点继续。每臂名义预算均为 **2B** `padded_tokens × 24 × 4 × T`，这是训练开销代理，不是实测 FLOPs。离散 batch 造成的终点误差、有效 token 数和实际总开销必须报告。

| 臂 | 每个同质难度 batch 的 T |
|---|---|
| conditional | d1/2→T4，d3/4→T6，d6/8→T8 |
| independent | 在同阶段内随机置换 conditional 的整条 T 序列，破坏难度与 T 的配对 |
| fixed4 | 所有难度均为 T4；同 2B 开销，作为实用基线 |

三个臂都用同质 difficulty 的 optimizer batch：每次更新的 16 个例子具有同一 d，microbatch=8。不能拿 v2 的混合难度 batch 训练结果充当这里的 fixed4 控制。模型结构、可训练参数、单出口答案 CE、优化器、裁剪、学习率峰值和数据格式沿用 v2；完整 BPTT 与 checkpointing，不添加浅层错误标签、梯度截断、单调性奖励或新 halting 机制。

| 预算阶段 | q(d1,d2,d3,d4,d6,d8) | conditional / independent 的 T4,T6,T8 目标边缘分布 |
|---|---|---|
| 0–15% | .20,.60,.20,0,0,0 | .80,.20,0 |
| 15–40% | .10,.20,.30,.40,0,0 | .30,.70,0 |
| 40–70% | .10,.10,.10,.25,.45,0 | .20,.35,.45 |
| 70–100% | .10,.05,.05,.15,.30,.35 | .15,.20,.65 |

## 3. 配对控制与可恢复执行

采用预生成清单方案，而非只匹配期望边缘分布。按表中 q 生成每阶段的共同 batch 清单及例子 ID，记录 conditional 的 T=f(d)，再用独立 RNG 在阶段内置换 T 给 independent。每阶段的实际 T 次数、样本顺序、更新数因此完全相同；随机置换并不保证有限样本的 d–T 列联表恰好独立，必须报告实际列联表，不能按结果重新抽置换。

所有训练 batch 固定为同一 padding width L；L 在启动前从训练数据及 tokenizer 确定，保证无截断。这样 conditional 与 independent 的每阶段总开销代理精确一致，长度与 T 的相关性也不会改变总开销。以 conditional 清单累计开销达到预定阶段界限（累计 0.3/0.8/1.4/2.0B）确定共同阶段终点；independent 按同一清单边界推进，不能各自按实时开销重新切阶段。最后一次更新的预算超额有界并公开。

两匹配臂在相同更新位置使用相同 LR：阶段内以 `阶段起点实际开销 + 已完成更新数 / 阶段更新数 × 阶段实际总开销` 作为共同调度进度，保持 5% warmup 与 cosine。否则置换 T 会连带改变同一个例子的 LR。fixed4 使用相同开销进度曲线、阶段任务分布和固定 L，运行到同样的阶段预算（最多一更新的取整差）；每阶段先用同一批次流的共同前缀，再继续该流取得额外更新。它在同预算下会看到更多例子；这是固定开销基线的属性，不能声称它与另外两臂曝光相同。

预先固定并分别保存任务类别 RNG、每个 d 的无放回 pool/shuffle RNG、T 置换 RNG 和模型 RNG。阶段清单及每臂游标随 checkpoint 保存，resume 不重抽清单；任务选择和 T 都不依赖答案、模型正确率或开发集表现。采用前需验证一次实际 trainer 的中断续训等价，以及清单的样本、T 计数和开销匹配。固定 padding 的额外成本和保存清单的工程量有限，值得用于隔离本实验的核心变量。

## 4. 数据、冻结终点与防止伪收益

沿用 25 节点、随机双字母标签、原始无缩进边列表和 A–H 选择格式。新训练集 24k（d1/2/3/4/6/8 各 4k）；图身份排除所有先前实验，答案不参与采样。新 DEV 至少每跳 128 条；另生成从未用于设计选择的 sealed 集：已见 d1/2/3/4/6/8 每跳 512 条，以及**主要长度泛化集 d9/10/11/12 每跳 512 条**，每跳答案均衡。原 v2 sealed 和此次用于采用决策的新增 DEV 始终保留原身份，不能改名为 v3 主终点。

只比较预定最终预算 checkpoint。主指标是新 sealed d9–12 汇总的全词表正确率，T4→T8 配对；选择内正确率及每跳结果为次要指标。报告 wrong→right、right→wrong、保守配对置信区间及 exact McNemar。要支持本候选的完整结论，须同时满足：

- conditional T8 胜过自身 T4、fixed4 臂的 T4、independent 臂的 T8，三项预定配对增益的 95% 下置信界都大于 0；第三项才隔离“难度与 T 配对”的贡献。
- conditional 的 d1 T4 相对初始化须保持在 2 个百分点以内。另完整报告已见 d6/8 与新 d9–12 的 T4 相对 independent、fixed4 和初始化的差值及区间。硬题浅层下降超过 2pp 时，不能声称整体能力保持或无代价改进；但若 T8 的绝对准确率仍超过以上两个训练控制，则可以报告存在浅层代价的深层收益。这里的 2pp 是点估计护栏，不是统计非劣效性证明。

若 T8−T4 变大只因为 T4 下降，且 T8 没有胜过训练控制组，应报告深度专门化或退化，不能归因于额外的绝对能力提升。若 T8 胜过控制组而硬题 T4 有下降，须同时报告深层收益和浅层代价；本阶段用户目标并不要求所有难题在浅层也保持最优。简单题保持护栏仍为必需。T6/T12/T16、原 v2 OOD 和中途 DEV 曲线均不能补救失败的主终点。

本实验检验的是**未见题目长度的泛化**：T8 本身在训练中出现过，不能声称未见循环深度外推。未来确认工具必须显式新增 v3 的 d9–12 主分组，不能沿用现有比较器的 `hard=d6/8` 决策。一次 seed 是探索性证据；算术迁移、普遍 LLM 推理和自适应计算均留待独立实验。达到采用门槛只表示这一假设值得检验；在用户已授权的研究范围内，仍应先定稿协议和必要实现，再启动对应实验。
