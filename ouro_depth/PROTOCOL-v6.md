# V6：逐轮节点监督能否让循环块学会“每轮走一跳、到目标即停”

状态：2026-09-13 起草，V5 四臂完成训练后、V5 最终比较与本实验任何模型评分之前冻结。新的假设与新的确认；不改 V5。

## 1. 依据

V5 的七出口 d×T 矩阵给出了比“过度计算漂移”更精确的诊断：

- fixed4 训练的初始化在**额外循环中继续沿链前进**：T6 解 d9（77%）与 d10（63%），T8 解 d10（66%）与 d12（38%），但 d4–d8 在 T6/T8 被“走过头”覆盖（d8：95%→16%→7%）。循环块已是一个迭代的“走跳”算子，缺的是**在目标处停住**。
- V5 的 progressive 信号（终点 CE + 随机无梯度前缀）教会了保持：d≤8 在 T8–T16 大幅回升（例如 prog16b 最终 d8/T16 = 73%，初始化 23%），但同时压制了越界带来的 d10/d12 收益，d10–12 在所有出口接近随机。终点监督无法告诉模型“数到 d 再停”，模型在训练范围之外没有计数依据。

因此需要一个**按轮定义工作量**的训练信号：第 r 轮出口应给出从起点走 min(r, d) 跳后的节点。若这一信号让 d9–12 在 T≥d 的出口被解出（训练只到 d8），则“每轮一跳 + 到点即停”这一算法在深度上外推；若终点监督对照做不到而它做到，就回答了研究目标里“监督位置与目标”这一变量。

## 2. 任务与数据（pointer-node）

同 25 节点单向环与提示措辞，去掉 A–H 选项，答案是节点本身。节点标签限定为 Ouro tokenizer 中“空格 + 两字母”恰为单 token 的 319 个串（`artifacts/v6-single-token-labels.json`），因此每个出口都能用全词表 next-token CE 监督任意一跳的节点。`prepare_v6_data.py`（seed 20260918）生成：训练 d∈{1,2,3,4,6,8} 各 4,000；DEV d1–12 各 128；密封 test d1–12 各 512；探索性探针 33 节点 d13–16 各 64。图身份与全部既有 25 节点语料互斥。每行携带完整路径。

## 4. 臂（同批、同 T、同 LR，只有监督不同）

| 臂 | 监督 |
|---|---|
| step | 出口 r=1…T，目标 = 走 min(r, d) 跳后的节点（含到点后的保持目标） |
| step_nohold | 出口 r=1…d，目标 = 走 r 跳后的节点；r>d 不监督 |
| terminal | 仅出口 T，目标 = 走 d 跳后的节点（难度配深度 + 保持，无逐轮对齐） |
| fixed8 | T 恒为 8，仅出口 8，目标 = 走 d 跳后的节点（本格式内的传统固定深度训练） |

step 对 terminal 隔离“逐轮对齐”；step 对 step_nohold 隔离“保持目标”；fixed8 是本格式下与 V4/V3 fixed 训练同类的对照。四臂各占一张 GPU（若 GPU4/6 仍被他人占用，则两臂共用一张空闲卡）。

## 5. 预先固定的判断（主终点 1448，主候选 step，主组未见 d9–12，n=512，全词表正确率）

1. **深出口有效：** `A(step,T16) − A(step,T8) > 0`，配对 exact McNemar p<.05。
2. **逐轮监督的贡献：** `A(step,T16)` 显著高于 `A(terminal,T16)` 与 `A(fixed8,T16)`（同推理深度）。
3. **超过所有对照最强出口：** `A(step,T16)` 显著高于 max over {terminal, fixed8, step_nohold} × T∈{1…16}；5pp 实用余量单独报告，是开封 test 的条件。
4. **一跳一轮外推：** 对 d∈{9,10,11,12} 各自，`A(step, T=d) ≥ 50%`（训练最深 d=8、T≤12）。这是本实验特有的机制判断。
5. **保持：** d1、d2 在 T16 ≥ 95%；d6、d8 在 T16 ≥ 90%。
6. **无越界回落：** `A(step,T16) ≥ A(step,T12) − 2pp`。

判断 1–3 构成主家族，Holm 校正；4–6 为观测阈值。六项全过为 DEV 通过；通过且 5pp 余量成立才开封密封 test，用同样的三个主对比确认。机制证据另报：每个出口预测节点落在环上的第几跳（`landed_hop`）的均值与分布——“每轮一跳”应表现为 r<d 时均值≈r、r≥d 时≈d；越界表现为均值持续增长。

结论分级沿用 V5 修订：hold 级（4–6 成立且 T16 不劣于最强对照出口 2pp 以内）与 continue 级（1–3 成立）分开措辞；只有 continue 级对应研究目标第一阶段。

## 6. 解释边界

- 答案格式改变，数值不能与 V1–V5 直接比较；terminal/fixed8 是本格式内的对照。
- step 监督显式规定了每轮一跳的算法，这是有意为之：研究变量是训练信号。若 step 外推而 terminal 不外推，说明深循环能力需要按轮定义的目标；若 step 也不外推，说明隐式计数本身不外推，需要新的机制（例如显式剩余跳数）。
- 从原始权重直接训练有塌缩先例（V4）；分阶段课程和 warmup 是缓解而非保证。若某臂在 362 步 DEV 上 d1/T1 < 90%，记为任务学习失败并如实报告，不追加预算或调参。
- 单 seed，无独立初始化重复；33 节点探针只作描述。

## 7. 停止与不得为之

非有限 loss/梯度、OOM 或检查点损坏时停止并保留现场；门槛失败不延长、不换出口、不换检查点；密封 test 只在 DEV 通过且余量成立后一次性评分；探针结果不进入任何门槛。
