## Format probe

A CPU tokenizer audit found query/source IDs for the same two-letter node differed in254/256 sampled original training prompts. Adding one leading space before each relation source aligned them in256/256 without changing facts or labels. A512-pair, base-model-only test compared original and indented held-out one-hop prompts:

-4-loop accuracy:19.14%→19.34%;21 wrong→right and20 right→wrong.
-8-loop restricted-choice accuracy:15.43%→16.60%;19 wrong→right and13 right→wrong.

This probe provides no large observed improvement from indentation. It changes spaces, token boundaries and length together, so it cannot isolate tokenization as a sole cause. One-hop training already succeeds in the original format; retain it for the next stage.
